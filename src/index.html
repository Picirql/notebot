✦ NoteBot AI

Transform your class recordings, transcripts, and lecture notes into beautiful, structured study notes using Google Gemini AI — in seconds.

What is NoteBot AI?

NoteBot AI is a free AI-powered note-taking tool designed for students. Upload a class transcript or lecture resource file and choose a note style — the app uses Google Gemini to instantly generate comprehensive, well-formatted study material tailored to your needs.

Features

  • 📄 Upload class transcripts (JSON, TXT, or Markdown)
  • ✨ Six note presets: Detailed Notes, Summary, Key Concepts, Flashcards, Study Guide, Formula Sheet
  • ⚡ Live streaming — watch notes generate in real time
  • 📐 LaTeX math rendering for science and engineering subjects
  • 💻 Syntax-highlighted code blocks
  • 💾 Notes saved locally in your browser — no account needed
  • 📤 Export as Markdown or plain text
  • 🔍 Search and revisit all your saved notes

How to Use

  1. Upload your class resource file (drag and drop or click to browse)
  2. Select a note style preset (Notes, Flashcards, Summary, etc.)
  3. Optionally add custom instructions
  4. Click Generate Notes and watch them stream in live
  5. Copy, export, or search your saved notes from the sidebar

Supported Subjects

Mathematics, Physics, Chemistry, Biology, Computer Science, History, Economics, Literature, Engineering, and any other subject covered in your class recordings.

⚙ Settings

Override the server default with your own key. Stored only in this browser — never sent to any third party.
